# Catálogo Comercial — versão 2

Versão refeita para teste com imagens locais no próprio projeto.

## Estrutura
- **Início**: capa independente com resumo e logos oficiais das empresas.
- **Catálogo**: tela independente com busca, filtros, cards e carregamento progressivo.
- **Contato**: tela independente para atendimento e redes.
- **Produtos**: imagens locais em WebP dentro de `assets/produtos` e miniaturas em `assets/thumbs`.
- **Logos**: arquivos locais em `assets/logos`.

Não depende de Postimg ou Supabase para carregar as fotos dos produtos.
